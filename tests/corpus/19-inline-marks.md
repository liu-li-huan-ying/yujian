# 内联标记：下标 / 上标 / 高亮

水的化学式是 H~2~O，质能方程 E=mc^2^ 里的 ^2^ 是上标。

高亮用 ==双等号== 包裹，比如 ==这段需要强调==。

混排一行：H~2~O 与 ==高亮== 与 x^2^ 同时出现，互不干扰。

* 列表里也能用：~下标~ / ^上标^ / ==高亮==
* 三项齐全，用来验证序列化不会被 GFM 删除线吞掉

> 引用块内：==高亮引用== 与 H~2~O

单个 `~` 不得被规范化为 `~~`（GFM singleTilde 的坑），这是本用例的核心红线。

定界符写在行内代码里时不参与解析：`~a~` 与 `^a^` 与 `==a==`。
