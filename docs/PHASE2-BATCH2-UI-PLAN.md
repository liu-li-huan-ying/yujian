## 4. 像素规格（全部引用现有令牌，新增 ≤ 3 个）

### 4.1 标题栏两开关（`.tbtn` 切换）

* 顺序：视图组现有 `[渲染|源码][侧栏][大纲][查找]` 之后追加 `[快照][凝神]`。
* 激活态：复用 `.tbtn--on`（`--hue-accent` 文字 + `--hue-active` 底），与侧栏/大纲开关同一语义。
* 图标：`history`(快照) / `moon`(凝神)；尺寸 16、28×28，与同组一致。

### 4.2 快照面板 `SnapshotPanel.vue`（玻璃）

* 容器：`.glass`，`position:absolute; top:10px; right:12px; width:420px`（同 FindPanel 定位语言，不进编辑区 DOM）。
* 头部：标题 `L.snapshots` + 关闭 ✕ + 「保存快照」按钮（即时留档，弹备注输入，可选填）。
* 列表项：时间（`YYYY-MM-DD HH:mm`）12.5px `--hue-text-1` + 备注（若有，`--hue-text-3` 斜体）+ 字数差（`+120 / -30`，增色 `--hue-success`、删色 `--hue-danger`）。
* 选中列表项 → diff 区：`jsdiff` 行级 diff，新增行左边 `--hue-success` 细条 + 淡底，删除行 `--hue-danger` 细条 + 淡底；等宽 12px。
* 操作：`[恢复]`（把快照内容 `setMarkdown` 载入编辑器并标 dirty，**不立即覆盖磁盘**，守红线 1）/ `[删除]`（走回收站）；列表项右键 `ContextMenu` 复用「恢复/删除」。
* 空态：玉质 hover 文字「暂无快照，保存或点击「保存快照」留档」。

### 4.3 写作统计（状态栏 + 玻璃弹层）

* **状态栏紧凑读数**（内联在 `App.vue` footer，`.jade`）：默认显示 `汉字 1.2k · 词 340 · 字符 2.1k · 阅 4′`；11px `--hue-text-3`，与现有 `选区`/`已保存` 同族。
* **统计弹层 `StatsPopover.vue`**（玻璃，点读数展开）：
  * 细分：汉字 / 英文单词 / 总字符(含空白) / 总字符(不含) / 阅读时长（中 300 字·分、英 200 词·分混合估）。
  * **选中统计**：选区非空时独立一节「选区：汉字/词/字符」，复用批次一选区监听。
  * **写作目标**：输入框设目标字数（汉字）；SVG **进度环**（`--hue-accent` 描边 + 背景轨道 `--hue-border-subtle`），完成度文字 `1.2k / 3k (40%)`；目标存 `session`（持久化）。

### 4.4 凝神模式（打字机 + 禅 融合，EditorHost 内）

* **双效合一**：
  * **居中**（打字机）：当前编辑行（光标所在块）在视口内**垂直居中**，默认偏上 1/3 偏移（常量 `FOCUS_OFFSET = 1/3`，预留偏好可调）。
  * **沉浸**（禅）：当前块加 `.zen-active`（高亮：文字 `--hue-text-1` + 微弱 `--hue-tint` 底）；其余顶层块加 `.zen-dim`（`opacity: 0.38` 过渡 `var(--dur-fast)`）。
* 实现：
  * 居中用 PM `selectionChange` / `scroll` → `view.coordsAtPos` 取当前块中心 → `editorPane.scrollTo({ top, behavior:'smooth' })`，**rAF 节流**防抖。
  * 沉浸用非破坏性 PM 装饰（`zen.ts`），随光标所在顶层块刷新。
* **失焦暂停**：`focusout` 停止居中（避免非编辑时乱滚）；`focus` 恢复。
* **不与多标签/滚动保持打架**：仅当 `focusMode` 开启时生效；切 tab 时由 `captureScroll/restoreScroll` 接管，凝神居中在 `restoreScroll` 后延一帧（`requestAnimationFrame`）再居中。
* 偏好：标题栏 `凝神` 开关切换，`session` 持久化（`focusMode: boolean`）。

### 4.5 自动快照策略（守红线 1 / 本地真源）

* **保存即快照**：`EditorHost.save()` 成功后（防抖 800ms）调 `window.api.snapshotCreate(path, markdown)` 存一份。
* **定时快照**：仅当距上次快照有改动，每 10 分钟一份（renderer `setInterval` 校验改动时间）。
* **手动快照**：标题栏「快照」面板内「保存快照」按钮，可填备注。
* **存储位置**：`.yujian-history/<path-hash>/<ISO8601>.md`（独立于 `.mdeditor/`）；启动提示加进 vault `.gitignore`；导出/图床逻辑忽略。
* **保留策略**：默认每文档最多 50 份或 30 天（常量可配）；清理走回收站。

## 5. 数据流（守三条红线）

1. **Milkdown 单实例**：凝神/统计/快照全部在现有 `EditorHost` 单实例内做，绝不每文档建实例（守红线 2）。
2. **Markdown 往返保真**：快照只"读" `getMarkdown` 存盘，回滚 = `setMarkdown` 载入并标 dirty，**不立即覆盖磁盘原文**（守红线 1）；凝神用非破坏性 PM 装饰。
3. **禁编译型依赖**：仅新增 `jsdiff`（纯 JS）；其余零依赖。
4. **本地唯一真源**：快照存本地 `.yujian-history/`，图床/导出镜像逻辑忽略它。

## 7. 验收（对应计划 §5 批次二）

* 保存后 `.yujian-history/<hash>/` 生成快照文件；手动「保存快照」可填备注并落盘；
* 快照面板列表展示时间/备注/字数差；选中看 jsdiff 行级 diff（增/删着色正确）；
* 「恢复」把快照内容载入编辑器并标 dirty、磁盘原文未被覆盖；「删除」走回收站；
* 统计：汉字/英文词/字符(含·不含空白)/阅读时长 + 选区统计 + 目标进度环数值正确；
* 凝神：当前行垂直居中（偏上 1/3）+ 当前块高亮 + 余者降透明度；失焦暂停、切 tab 不冲突、平滑不抖；与渲染/源码两模式均生效；重启经 session 恢复；
* 风格：面板/弹层均为玻璃、状态栏/标题栏为玉质，与现有体系一致；编辑区纯净红线未被破坏；
* 性能：50+ 快照列表、长文档统计/凝神滚动无卡顿。

### 规模/边界验收

* 快照数 > 50 时列表可滚动；恢复大文档（>1MB）不卡 UI；
* 凝神在窄窗（<720px）/ 长文档下居中稳定、不触发页面级滚动跳动；
* 自动快照防抖正确：连续输入只在停顿后留一份，不每键一份。
