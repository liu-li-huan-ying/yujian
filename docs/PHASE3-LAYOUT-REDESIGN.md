# Phase 3 功能按键布局重分布（落实 PHASE3-UI-DESIGN §3）

> 状态：**Tier A + Tier B 已于 2026-09-04 落地**（轨道视图 + 菜单分组 + 语言移出状态栏）。Tier C（⌘P 命令面板）列入批次四待做。

## 1. 问题诊断（实查当前入口）

- 标题栏三组（文件 / 视图 / 分享工具）本身不乱，但「更多 ⌄」菜单已膨胀为 **14 项扁平长列表**，语义混杂（设置 / PKM 知识 / 编辑器动作 / 库安全 / 帮助）仅靠 2 条分隔线区分。
- 快照 / 凝神占标题栏常驻开关；而反链 / 标签 / MOC / 断链这些 PKM 核心能力反而埋进「更多」二级菜单。
- 语言切换挤在状态栏（它是设置不是状态）。
- 无命令面板：15+ 功能全靠菜单肉眼扫，发现成本高。

这正是 `docs/PHASE3-UI-DESIGN.md` §3.1 预判并警告过的「面板膨胀」，落地时因图省事做成 `v-if` 玻璃浮层 + 菜单入口而偏离了 §3 的「左右双栏多视图切换」正解。

## 2. 目标落点（落实 §3，按已建功能细化）

| 区域 | 承载功能 | 现状 |
|---|---|---|
| 标题栏三组 | 文件(＋/库/打开) · 视图(所见│源码/侧栏/大纲) · 分享(导出/外观/更多/帮助) | 零增长，不加按钮 |
| 左栏视图 tab | 文件树 / 搜索 / 标签 / 图谱(MOC+关系图) | 标签、MOC 从「更多」升常驻视图 |
| 右栏视图 tab | 大纲 / 反链 / 快照 | 反链、快照从浮层升常驻视图 |
| 状态栏小标记 | 已保存点 · 断链/自检告警(有才出现，点击展开) | 语言切换移出 |
| 命令面板 ⌘P | 链接检查 / 完整性 / 整库备份 / 写作辅助 / 插入双链 / 图床 / 凝神设置 / 外观 / 偏好 / 全部动作 | 任务型能力统一收纳 |
| 「更多」精简 | 外观 / 偏好 / 帮助 / 关于 | 仅剩低频设置 |

## 3. 对抗式打磨结论

- 支持方：轨道视图让 PKM 核心一眼可达；命令面板一次性解决 15+ 功能发现；标题栏零增长合规。
- 挑刺方：① 浮层→轨道视图需重写 8 面板 chrome；② §3「每栏单视图」令「同时看标签+反链」不可用；③ 命令面板属批次四大工程。
- 取舍：② 为 §3 已接受权衡；若用户坚持同屏，可改「右栏可堆叠 pane（Obsidian 式）」变体，但牺牲宽度不变约束，需拍板。① ③ 以分阶段化解。

## 4. 分阶段落地

- **Tier A（廉价，现在可做）**：仅用 `separatorTitle` 把「更多」菜单按「知识/工具/设置」分组 + 语言切换移出状态栏。约 30 行，不碰架构。
- **Tier B（正解，落实 §3）**：左右栏视图 tab，标签/反链/MOC/快照从浮层改轨道视图；标题栏不动。
- **Tier C（杠杆，批次四）**：命令面板 `Ctrl+Shift+P`，任务型能力全收；修 §3.4 的 `Ctrl+K`/`Ctrl+F` 键位不一致。

建议顺序 A→B→C（先最小端到端再叠加）。

## 5. 待用户拍板

1. 落地范围：A / A+B / A+B+C。
2. 右栏是否允许「同屏堆叠多个 pane」（牺牲宽度换同时看标签+反链），还是严格 §3 单视图。

## 6. 已落地实现（Tier A + B，2026-09-04）

**新增 `src/components/RailView.vue`**：通用轨道容器（图标 tab 条 + 内容槽 + 可选拖拽调宽）。用 `:deep()` 把被承载面板原本的 `position:absolute` 浮层样式中和成「填满轨道的一等公民」，无需改写各面板源码。

**左栏轨道**（`App.vue`）：`[文件(folder) | 标签(tag) | 内容地图(map)]`，承载 `Sidebar` / `TagPanel` / `MocPanel`。
**右栏轨道**（`App.vue`）：`[大纲(file-text) | 反链(backlink) | 快照(history)]`，承载 `Outline` / `BacklinksPanel` / `SnapshotPanel`，可拖拽调宽（220–560px）。

**入口变化**：
- 标题栏「更多 ⌄」按 `separatorTitle` 分组：**知识**（反链/标签/内容地图）· **工具**（链接检查/插入双链/写作辅助/完整性/整库备份/图床）· **设置**（语言/偏好/凝神设置）· **文件**（保存/另存/关于）。
- 语言切换从状态栏移入「更多 · 设置」（新增 `globe` 图标 + `L.language`）。
- 反链/标签/内容地图/快照不再以浮层出现，改由轨道 tab 承载；标题栏「快照」按钮现在 = 打开右栏「快照」tab（再点收起右栏）。
- 工具型面板（链接检查/完整性/整库备份/写作辅助）仍按需以浮层打开，符合「任务型」语义。

**数据刷新**：`TagPanel`/`MocPanel`/`BacklinksPanel` 在 `v-if` 挂载时 `onMounted` 自取数据；`SnapshotPanel` 自身不在挂载时拉取，故由 `App` 的 `watch([rightTab, filePath, outlineVisible])` 在其 tab 激活时触发 `snapshots.refresh`。

**取舍落地**：遵循 §3「每栏单视图」——同一栏一次只看一个视图，标题栏零增长。若日后要「同屏看标签+反链」，需改右栏为可堆叠 pane（Obsidian 式），属未来增强，不在本次范围。

**验证**：`typecheck` / `lint`(仅 2 历史 v-html 警告) / `build` 全绿；产物含 `rail__tabs`/`rail--right`/`menuGroupKnowledge`。本地提交待网络恢复后推送。
