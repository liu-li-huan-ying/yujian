玉笺写作：让视野随窗口呼吸

窗口变宽时，正文列也跟着等比例变宽——不是把字放大，而是每行能多容纳几个字，阅读节奏更顺。在默认尺寸下保持约 720px 的舒适阅读宽度，全屏时自然铺开到上限。

这一段是当前正在编辑的段落。在凝神模式下，它会字号微放大并轻微抬起，配合青瓷微光底衬，成为视觉焦点，让眼睛更轻松地落在正在写的地方——这是参考 iA Writer 焦点放大与 Typora 淡出思路融合后的处理。

其余段落按雾化距离逐档淡出，结构保留、文字退后，营造出「雾里看字、眼前清晰」的沉浸感。列宽上限守住 CJK 阅读舒适区（约 60 字/行），不会因超宽屏而变得难以回行。

「优秀的写作工具，应该让格式消失，只留下你和文字。」—— 列宽是这件小事里最容易被人忽略、却最影响长期舒适度的细节。

拖动上方滑块即可实时观察：从窄窗到 2560px 全屏，正文列如何从约 700px 平滑增长到约 920（常态）/ 1000（凝神）px，而字号始终不变。

设计取舍：列宽用 clamp(700px, 56vw, 920px)（凝神 clamp(760px, 62vw, 1000px)）绑定视口宽度—— 下限守住窄窗不挤压、上限守住超宽屏不过宽；字号恒定 16px，变的是「每行字数」而非「字的大小」。 凝神当前段 font-size:1.07em + scale(1.01) 提供视觉冲击，离开时平滑回弹（可关）。
