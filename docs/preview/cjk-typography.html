为什么是渲染层

用 Vue 3 与 Electron 构建的 Markdown 编辑器，支持 100% 离线、WYSIWYG 与源码双模式；导出 HTML / PDF / Word 皆可。

连续全角标点测试：「引号」、逗号，句号。（括号）《书名》！？—— 引擎会收紧行首与连续标点。

中文强调内容用强调色而非斜体；English emphasis also recoloured.

行内代码如 const x = 1 与汉字混排时同样补 ¼ em；而代码块内部不参与，避免变量名被撑开。

关掉上面的开关，段落间距、字距与强调样式会立刻回退到浏览器默认，对照一眼可辨。

· 逐项开关对照：中英 / 中数间距关掉后「Vue 3」会重新贴紧汉字；中文强调关掉后「强调内容」变回斜体；
· 段落间距关掉后段落行距收紧 4px；标点挤压影响全角标点的行首/连续收紧。
