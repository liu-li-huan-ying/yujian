中文双击选词对照

编辑器原生双击按「空格 / 词字符」切分，而中文词间没有空格——于是双击中文常常整段选中。
本页演示修复效果：点下面任意一个字，看「双击那里」会选中什么。上方是原生行为，下方是修复后。

当前浏览器不支持 Intl.Segmenter，无法演示。

修复后（中文按词边界）

选中的是一个词，不是整段
实现：判定逻辑抽为纯函数 src/utils/cjk-segment.ts（isCjkChar / segmentWords / wordRangeAt）， 编辑器侧由 src/editor/wordSelect.ts 接管双击。
分词直接用浏览器原生 Intl.Segmenter（ICU），零依赖、与系统输入法同源 —— 不引第三方分词库。 ICU 对未登录的双字词常切成两个单字（「开源」→「开」+「源」），故加了一层保守回退： 长度为 1 的汉字词若紧邻下一个单字，则合并为双字；相邻段只要不是单字（更长、或标点 / 西文），就绝不跨过去合并 （所以「我」+「喜欢」不会被拼成「我喜」，「编」也不会粘上后面的逗号）。
只在 CJK 上接管：拉丁字母、数字的双击仍走编辑器默认逻辑（它对西文更好）。 光标落在中文标点上时选中该标点本身。
