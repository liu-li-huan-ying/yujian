# 凝神模式 2.0 · 动效与交互设计规格（雾与纸）

> 状态：**已实现**（typecheck ✅ / build ✅）；运行期交互验收待用户 `npm run dev` 体验确认。
> 输入：外部软件凝神模式动效描述（门与墙隐喻）+ 玉笺 v1.1 玉质/玻璃设计体系（docs/UI-DESIGN.md）。
> 交互预览：`docs/preview/focus-mode-yujian.html`（可直接打开，含进场动画 / 轻退栏 / 设置面板实时预览）。
> 实现差异（与本稿的出入，以代码为准）：
> ① 设置面板入口：轻退栏 ⚙ 与标题栏「更多」菜单（moon 图标）双入口；命令面板入口留待后续；
> ② 纸卷滚动只在「脏」（选区/文档变化）时拉锚并收敛即停——用户滚轮浏览不被强行拉回，比本稿 §5 更保守；
> ③ 雾化距离按**文本块距**度量（§4 细化）：列表项 / 引用 / 表格单元格内的嵌套文本块也逐块计距淡出，
>    长列表不会再「整棵全亮」；无文本子节点的顶层叶块（图 / 分割线 / mermaid）按「其前的文本块数」雾化，
>    避免整块突兀停在满透明度；容器类视觉元素（表格网格 / 引用竖线 / 列表圆点）保持满透明度——
>    结构保留、文字退后，恰好强化雾的层次感；
> ④ 凝神下**源码模式也走居中列**：对称内边距 `max(0, 50% − 列宽/2)` 把「行号 + 代码」整体收进
>    居中列（列宽 = `--w-column-zen`，随窗口等比例更宽；行号随列移动），修复宽窗下 CodeMirror 整屏贴左的「非常偏左」观感（`styles/zen.css`）。

## 1. 设计基调：从「门与墙」到「雾与纸」

参考版的语言是**机械的**：门拉开、墙推进、坍下来——隐喻清晰但偏硬。
玉笺的材质体系（玉质框架 + 玻璃浮层 + 纯净内容层）决定了凝神 2.0 的语言应该是**纸墨的**：

* 侧栏不是「被拉开」，是**退入雾中**（位移 + 淡出同时发生，缓出曲线）；
* 正文列不是「被墙推进」，是**视野铺展**（`--w-column 720→--w-column-zen`，幅度随窗口等比例更宽，因为我们本来就是居中列，参考版的全宽收拢对我们不适用）；同时当前段落在凝神下**字号微放大 + 轻微缩放**，形成视觉焦点；
* 淡出不是「变灰」，是**墨迹遇雾**——距离衰减 + 内容列上下羽化遮罩共同营造；
* 整个过程**克制**：总时长与参考版相当，但每一段都更轻。

## 2. 差异决策表（参考版 → 玉笺 2.0）

| # | 参考版 | 玉笺 2.0 | 理由 |
| - | ------ | -------- | ---- |
| 1 | 双侧栏同时滑出（文件树+预览） | 文件树左退 + 大纲右退（我们的双侧是侧栏+大纲） | 结构对应 |
| 2 | 全宽文字收拢成窄列（大形变） | **视野铺展（常态列 `clamp(700px,56vw,920px)` → 凝神列 `clamp(760px,62vw,1000px)`，随窗口更宽）**，重形变放在「两侧退场」上 | 我们正文本就居中列；凝神要铺满视野营造沉浸感，而非收腰 |
| 3 | 进场 320ms 三段 | **进场 ~360ms 四幕**（见 §3），段间重叠 20–30ms | 幕间重叠让 360ms 观感仍是 320ms 级的干脆 |
| 4 | 退场 240ms 反向 | **退场 240ms 三幕**，完全采纳 | 「回来干活不需要仪式感」判断正确 |
| 5 | 行级均匀淡出（描述里的雾感） | **五档距离衰减 + 上下羽化遮罩**（§4） | 参考版文字描述的「前快后缓」正是当前实现（均一 .26）缺的 |
| 6 | 打字滚动缓动「纸在背后安静地卷」 | rAF lerp 弹性追随（§5），粘贴大段单帧限幅 | 与参考版行为一致，参数化 |
| 7 | Esc 轻退：32px 信息栏 | **采纳，玻璃材质**：居中悬浮胶囊（§6） | 这是最值得抄的交互；材质必须走玻璃体系 |
| 8 | 设置面板（6 项） | 采纳 5 项，**否决「光标闪烁频率」**（§7） | 原生 caret 闪烁频率浏览器/Electron 均不可定制；诚实替换为「当前块青瓷微光底衬」 |
| 9 | 进入时自动全屏 | 采纳（默认关） | Electron `win.setFullScreen`，低成本 |
| 10 | —（参考版无） | **保留现状**：失焦暂停滚动、切换 tab/模式自动退出凝神、`focusMode` 会话恢复 | v1 已验证的边界不回退 |

## 3. 动效时序

### 3.1 进场（~360ms，四幕，幕间重叠）

| 幕 | 时间轴 | 动作 | 缓动 |
| -- | ------ | ---- | ---- |
| 一 · 退入雾中 | 0 → 100ms | 侧栏 `translateX(-100%)` + `opacity→0`；大纲 `translateX(100%)` + `opacity→0` | `cubic-bezier(0.22, 1, 0.36, 1)`（easeOutQuint 系） |
| 二 · 框架收幕 | 80 → 200ms | 标题栏高度 38→0、状态栏 26→0，同步 `opacity→0`（各自向边缘坍落） | 同上 |
| 三 · 视野铺展 | 180 → 300ms | 正文列宽变宽（`--w-column → --w-column-zen`，随窗口等比例，CSS 变量过渡） | 同上 |
| 四 · 雾起锚定 | 280 → 400ms | ① 上下羽化遮罩淡入（各 48px）；② `.zen-dim-*` 各档 opacity 过渡淡入 120ms；③ 文档轻滚，把光标行送到锚点 | `ease-out` |

> 实现要点：幕四是**装饰淡入**而非瞬时打类——CSS transition 承担最后一幕，JS 只负责在 280ms 时挂类，避免装饰重算与布局动画叠加掉帧。

### 3.2 退场（240ms，三幕，反向但更快）

| 幕 | 时间轴 | 动作 |
| -- | ------ | ---- |
| 一 · 列松开 | 0 → 100ms | 正文列由凝神列回到常态列；雾与羽化遮罩淡出 100ms |
| 二 · 框架重生 | 60 → 180ms | 标题栏/状态栏从边缘长回 |
| 三 · 两翼归位 | 80 → 240ms | 侧栏/大纲滑回原位 |

### 3.3 `prefers-reduced-motion`

全部动画降级为 **120ms 交叉淡入淡出**（状态直接切换，无位移）；设置面板不提供额外开关，遵循系统偏好即可。

## 4. 雾化衰减（当前块之外的距离衰减）

按**文本块距 d** 分五档（当前实现是「当前块 + 其余均一 .26」两档，这是 2.0 的核心升级）：

| d（与当前文本块的块距） | 中档（默认） | 快档 | 慢档 |
| ---- | ---- | ---- | ---- |
| 0（当前文本块） | 1.0 + 青瓷微光底衬 | 1.0 | 1.0 |
| 1 | 0.55 | 0.45 | 0.66 |
| 2 | 0.38 | 0.28 | 0.50 |
| 3 | 0.28 | 0.20 | 0.40 |
| 4 | 0.22 | 0.17 | 0.32 |
| ≥5（趋同层） | **0.18** | 0.16 | 0.26 |

* 曲线特征：**前两跳掉得快（−0.17/跳），远处趋同（差 ≤0.04）**——余光不被文字墙拽走，抬眼即找回上下文。
* **距离在全部文本块上度量（含嵌套）**：`buildDecorations` 按文档序遍历所有文本块（列表项 / 引用 / 表格单元格内的段落都算），
  雾化档 = 与当前文本块之间隔了几个文本块。长列表 / 长表格内部逐块淡出，不再「整棵全亮」。
* **顶层叶块（图 / 分割线 / mermaid 等无文本子节点的块）**按「其之前的文本块数」取距雾化，避免漏档突兀。
* 类只挂在文本块与叶块上，容器（ul / blockquote / table）本身不挂类 → 嵌套文本块各自只收一档 opacity，无透明度复合叠加；
  容器视觉元素（表格网格 / 引用竖线 / 列表圆点）保持满透明度——结构保留、文字退后。
* 实现为 6 个类 `.zen-dim-1..5`（+ `.zen-active`），CSS 变量 `--fog-1..5` 承载档位，换档只改变量。
* **只用 opacity，不用 filter: blur**（大文档逐块 blur 必掉帧）；「雾感」由衰减曲线 + 内容列上下各 48px 渐变羽化遮罩（容器级，单元素，零逐块开销）共同完成。
* 大纲/字数等周边 UI 在凝神下隐藏，装饰只作用于正文块。

## 5. 打字滚动（纸卷）

* rAF 循环，lerp 追随：`current += (target − current) × k`，`target = 光标行顶 − 视口高 × 锚点`。
* 三档平滑度：跟手 `k=0.16`（默认）/ 平滑 `k=0.10` / 极平滑 `k=0.06`。
* **粘贴大段**：单帧位移限幅 `min(Δ, 120px)`——先匀速补偿再自然减速刹住，不跳帧（lerp 自带缓出，无需额外弹簧）。
* 静差 < 0.5px 停帧；失焦暂停；与 `captureScroll/restoreScroll`、多标签互不打架（沿用 v1 边界）。

***

## 6. 轻退栏（Esc 一次）

**这是本次最值得采纳的交互**：凝神中按 Esc 不退出，只「掀起帘子看一眼」。

* **形态**：居中悬浮胶囊，高 **32px**，宽随凝神正文列（随窗口等比例），顶部滑入 160ms + 淡入；不占布局空间（`position: fixed`）。
* **材质**：玻璃——`backdrop-filter: blur(28px) saturate(170%)` + inset 1px 高光 + 12px 圆角；与命令面板/对话框同体系。
* **内容**（从左到右）：文件名（中段截断）`·` 汉字数 `·` 最后保存时间（相对时间「3 分钟前」）｜右侧：`切换文档 ▾` `退出凝神`。
* **交互状态机**：
  * 凝神中 `Esc` → 栏滑入；再 `Esc` 或**点击编辑区** → 滑出（回凝神）；再 `Esc` 又滑入（可循环）。
  * 栏上「退出凝神」→ 走 3.2 退场；`切换文档 ▾` → 打开当前标签列表（复用「更多」下拉数据源）。
  * 正常模式下 Esc 无此行为（避免与源码模式 Esc 冲突）。

入口：轻退栏 ⚙ 图标 + 标题栏「更多 ⌄」菜单 + 命令面板。玻璃模态，宽 480px，改即生效（实时预览），无保存按钮。

| 设置项 | 取值 | 默认 | 持久化 |
| ------ | ---- | ---- | ------ |
| 锚点位置 | 正中 50% / 黄金分割 38.2% / 偏上 1/3 | 偏上 1/3 | `SessionState.zenPrefs.anchor` |
| 雾化衰减 | 快 / 中 / 慢 | 中 | `zenPrefs.fog` |
| 滚动平滑度 | 跟手 / 平滑 / 极平滑 | 跟手 | `zenPrefs.scroll` |
| 进入时自动全屏 | 开 / 关 | 关 | `zenPrefs.fullscreen` |

| ~~光标闪烁频率~~ | — | — | **否决**：原生 caret 不可定制；替换为「当前块青瓷微光底衬」（`.zen-active` 背景 +2% 青瓷提亮，纯 CSS） |

## 9. 验收标准

1. 进场：四幕依序发生且总时长 ≤ 400ms；期间无跳帧（DevTools Performance 无长任务）；动画完成后雾化五档与锚点同时就位。
2. 退场：240ms 反向完成后，侧栏宽度、列宽、滚动位置与进入前逐像素一致。
3. 打字：连续输入时当前行屏幕位置稳定（±1px）；粘贴 500 行后滚动匀速补偿、缓出刹住、无跳帧。
4. 雾化：当前行外第 1/2/3 块 opacity 与 §4 表一致；远处（≥5）肉眼不可分辨档差；大文档（500+ 块）滚动流畅。
5. 轻退：Esc 滑入/滑出各 160ms；「退出凝神」走标准退场；点编辑区收起；循环 Esc 行为符合状态机。
6. 设置：每项改动实时生效且重启后恢复；「光标闪烁频率」不存在于任何 UI。
7. `prefers-reduced-motion` 开启时全部动画 ≤120ms 且无位移。
